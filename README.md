# Arhimed Bot

**Arhimed Bot** — это Telegram-бот коммерческой школы *Архимед*, разработанный на Python. Проект имеет модульную структуру, разделяющую логику работы с базой данных, интерфейсом (клавиатурами) и текстовыми сообщениями. 

**Основная задача** *— поиск и привлечение потенциальных колиентов (лидов).*

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd arhimed_bot
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации
1. Переименуйте файл `config.example.py` в `config.py`.
2. Откройте `config.py` и вставьте ваш токен бота (полученный у [@BotFather](https://t.me)), а также настройте другие параметры, если они есть.

### 5. Запуск бота
```bash
python main.py
```

## 🛠 Используемые технологии
* **Python 3.12.10**
* **aiogram**
* **SQLite**
